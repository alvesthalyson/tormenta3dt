# Tormenta 3D&T — MVP Foundry v13

Esta é a primeira estrutura instalável do sistema. A próxima etapa é substituir a ficha padrão do Foundry por uma ficha própria e adicionar rolagens de ataque, defesa, dano e Disposição.

## Instalação local

Copie a pasta `foundry-system` para a pasta `Data/systems/` da sua instalação do Foundry. Depois reinicie o Foundry e crie um mundo usando o sistema **Tormenta 3D&T**.
